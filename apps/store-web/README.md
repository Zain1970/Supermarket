# واجهة إدارة المتجر

واجهة React + Vite + TypeScript عربية RTL تتصل بواجهة API الحالية، ولا تستخدم بيانات تجريبية.

## التشغيل

1. ثبّت Node.js 20 أو أحدث وPostgreSQL، ثم أعد إعداد API وفق التعليمات في المستودع.
2. شغّل API على `http://127.0.0.1:4000`.
3. من جذر المشروع نفّذ `npm install` ثم `npm run dev:store-web`.
4. افتح العنوان الذي يعرضه Vite. يمرر Vite طلبات `/auth` و`/stores` و`/admin` إلى API لتبقى جلسة cookie على نفس الأصل أثناء التطوير.

## المتوفر حاليًا

- تسجيل الدخول والخروج باستخدام جلسة API.
- تحميل المتاجر التي يملك المستخدم عضوية فيها واختيار المتجر الحالي.
- عرض المنتجات النشطة، والبحث بالاسم أو SKU أو الباركود، وإنشاء منتج عبر API المحمي.
- عرض العملاء وإنشاء عميل مع حد ائتماني اختياري، دون تعديل رصيد العميل مباشرة.
- عرض الفواتير المسجلة وحالات الدفع والأرصدة المستحقة، مع تسجيل دفعات لاحقة للفاتورة وتحديث الرصيد وحالة التحصيل من الخادم.
- نقطة بيع أولية: اختيار المنتجات والكميات والعميل وطريقة الدفع والخصم، ثم إنشاء الفاتورة باستخدام مفتاح idempotency. يتحقق الخادم من المخزون وحد الائتمان ويحدّث المخزون وحركاته ضمن معاملة واحدة.
- تقرير يومي مبني على المبيعات الفعلية؛ تُظهر الواجهة أن الربح غير متاح إذا كانت تكلفة البضاعة غير مكتملة.
- تنبيهات مخزون منخفض من API، مع بحث بالاسم أو SKU أو الباركود، وتظهر فقط للأدوار المسموح لها بحسب صلاحيات الخادم.
- سجل حركات المخزون مع تصفية حسب المنتج، وتسويات إضافة/خصم مع سبب إلزامي ومفتاح idempotency. يرفض الخادم السحب غير المسموح ويكتب حركة وسجل تدقيق.
- نقطة بيع أولية تستخدم الأسعار والمخزون في الخادم عند إنشاء الفاتورة، وتدعم الخصم والدفع الكامل أو الجزئي أو الآجل ومفتاح idempotency.
- إنشاء مرتجع مخزني من الفاتورة للأدوار المخولة فقط؛ يختار المستخدم الأصناف والكميات ويُدخل السبب، ويمنع الخادم تجاوز الكمية المتبقية. هذه العملية لا تصدر ردًا نقديًا ولا تعدّل الدفعات.
- إدارة الباقات والاشتراكات والإضافات للمالك والمدير: عرض الباقات الحالية وطلبات الاشتراك، بدء التجربة إن كانت متاحة، وطلب الإضافات. لا تُفعّل الواجهة أي ميزة قبل اعتماد الدفع من مسؤول المنصة.
- مساحة Super Admin تعتمد على حقل `isPlatformAdmin` من جلسة الخادم، لمراجعة طلبات الدفع واعتمادها أو رفضها بسبب مسجل، مع عرض كتالوج الباقات والإضافات.
- تصميم متجاوب يدعم العربية واتجاه RTL على الهاتف والحاسوب.
- مؤشرات المخزون محسوبة من أول 100 منتج محمّل، وتوضح الواجهة حد النتائج بدل الإيحاء بعرض كل السجلات.

## التحقق

```bash
npm run typecheck:store-web
npm run build:store-web
```

هذه الواجهة تغطي شريحة أساسية من إدارة المتجر وليست اكتمالًا لجميع متطلبات المنتج. لا تزال صفحات الموردين والمشتريات والطلبات والإعدادات، وإدارة المخزون المتقدمة والجرد الشامل، وسير عمل المرتجعات من الواجهة، وربط نقطة البيع بإضافة مدفوعة والتحقق من استحقاقها، ولوحات Super Admin، وتطبيقات الهاتف بحاجة إلى مراحل تنفيذ واختبارات مستقلة.
