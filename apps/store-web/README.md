# واجهة إدارة المتجر

واجهة React + Vite عربية RTL تتصل بواجهة API الحالية، ولا تستخدم بيانات تجريبية.

## التشغيل

1. ثبّت Node.js 20 أو أحدث وPostgreSQL، ثم أعد إعداد API وفق التعليمات في المستودع.
2. شغّل API على `http://127.0.0.1:4000`.
3. من جذر المشروع نفّذ `npm install` ثم `npm run dev:store-web`.
4. افتح العنوان الذي يعرضه Vite. يمرر Vite طلبات `/auth` و`/stores` إلى API لتبقى جلسة cookie على نفس الأصل أثناء التطوير.

## المتوفر

- تسجيل الدخول والخروج باستخدام جلسة API.
- تحميل المتاجر التي يملك المستخدم عضوية فيها.
- اختيار المتجر وعرض المنتجات النشطة من API.
- البحث بالاسم أو SKU أو الباركود.
- إنشاء منتج مع التحقق من المدخلات في الخادم.
- مؤشرات أولية مبنية على المنتجات التي تم تحميلها، مع إظهار واضح لحدّ 100 منتج.

هذه بداية للواجهة وليست اكتمالًا لمتطلبات المنتج. لا تزال صفحات العملاء والمشتريات والطلبات والإعدادات والتقارير وPOS وتطبيقات الهاتف بحاجة إلى التنفيذ.
