# واجهة إدارة المتجر

واجهة React + Vite + TypeScript عربية RTL تتصل بواجهة API الحالية، ولا تستخدم بيانات تجريبية.

## التشغيل

1. ثبّت Node.js 20 أو أحدث وPostgreSQL، ثم أعد إعداد API وفق التعليمات في المستودع.
2. شغّل API على `http://127.0.0.1:4000`.
3. من جذر المشروع نفّذ `npm install` ثم `npm run dev:store-web`.
4. افتح العنوان الذي يعرضه Vite. يمرر Vite طلبات `/auth` و`/stores` و`/admin` إلى API لتبقى جلسة cookie على نفس الأصل أثناء التطوير.

## المتوفر حاليًا

- تسجيل الدخول والخروج باستخدام جلسة API.
- تحميل المتاجر التي يملك المستخدم عضوية فيها واختيار المتجر الحالي.
- عرض المنتجات النشطة، والبحث بالاسم أو SKU أو الباركود، وإنشاء منتج عبر API المحمي.
- عرض العملاء وإنشاء عميل مع حد ائتماني اختياري، دون تعديل رصيد العميل مباشرة.
- عرض الفواتير المسجلة وحالات الدفع والأرصدة المستحقة.
- تقرير يومي مبني على المبيعات الفعلية؛ تُظهر الواجهة أن الربح غير متاح إذا كانت تكلفة البضاعة غير مكتملة.
- تصميم متجاوب يدعم العربية واتجاه RTL على الهاتف والحاسوب.
- مؤشرات المخزون محسوبة من أول 100 منتج محمّل، وتوضح الواجهة حد النتائج بدل الإيحاء بعرض كل السجلات.

## التحقق

```bash
npm run typecheck:store-web
npm run build:store-web
```

هذه الواجهة تغطي شريحة أساسية من إدارة المتجر وليست اكتمالًا لجميع متطلبات المنتج. لا تزال صفحات الموردين والمشتريات والطلبات والإعدادات، وإدارة المخزون التفصيلية والمرتجعات، وPOS مع التحقق من استحقاق الإضافة، ولوحات Super Admin، وتطبيقات الهاتف بحاجة إلى مراحل تنفيذ واختبارات مستقلة.
