# Supermarket — منصة إدارة السوبر ماركت متعددة المتاجر

حالة المشروع: **نواة برمجية أولية قيد التطوير، غير جاهزة للإنتاج.**

الهدف هو بناء منصة SaaS عربية RTL لإدارة عدة متاجر مع عزل بيانات المستأجرين، اشتراكات، وإضافات مستقلة مدفوعة مثل POS وAI Analytics.

## التقنيات

- Node.js + Express + TypeScript
- Prisma + PostgreSQL
- React + Vite للواجهات الويب
- React Native + Expo لتطبيقات الهاتف
- OpenAPI واختبارات آلية

## ما هو موجود حاليًا

- نقطة فحص صحة API: `GET /health`.
- مخطط Prisma أولي للمتاجر والمستخدمين والعضويات والتدقيق والمنتجات والمخزون والباقات والاشتراكات والإضافات والمدفوعات.
- قواعد أولية قابلة للاختبار للتحقق من عضوية المستخدم في المتجر والأدوار.
- سياسة أولية للتحقق من استحقاق الإضافات على الخادم.
- اختبارات مصدرية لهذه القواعد، لم تُشغّل محليًا بعد.
- سير GitHub Actions لفحص النوع والاختبارات والبناء، لم يُثبت نجاحه بعد.

## تشغيل مبدئي

المتطلبات: Node.js 20 أو أحدث، وPostgreSQL عند استخدام قاعدة البيانات.

```bash
cp .env.example .env
npm install
npm run dev:api
```

عنوان فحص الصحة بعد تشغيل API: `http://localhost:4000/health`.

## تحذيرات مهمة

- لم تُنفذ المصادقة الفعلية أو إدارة الجلسات بعد.
- لم تُربط قواعد الوصول بقاعدة البيانات أو بمسارات تجارية محمية.
- لم تُنشأ ترحيلات قاعدة بيانات ولم يُتحقق من المخطط بأداة Prisma.
- لا تستخدم المشروع مع بيانات حقيقية أو في الإنتاج قبل إكمال الاختبارات الأمنية والتشغيلية.
