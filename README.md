# Supermarket — منصة إدارة السوبر ماركت متعددة المتاجر

حالة المشروع: **مرحلة التأسيس والتقييم؛ لا يوجد تطبيق منفذ بعد.**

الهدف هو بناء منصة SaaS عربية RTL لإدارة عدة متاجر مع عزل بيانات المستأجرين، اشتراكات، وإضافات مستقلة مدفوعة مثل POS وAI Analytics.

## قرار البداية

تمت مراجعة أولية لعدد من المستودعات العامة وتراخيصها. التوصية هي بناء المشروع من الصفر، مع استخدام مرشحين خارجيين كمرجع معماري فقط، لأن أي مرشح لم يثبت بعد أنه يغطي المتطلبات كلها مع التوافق المطلوب. راجع [تقييم المستودعات](REPOSITORY_ASSESSMENT.md).

## التقنيات المستهدفة

- Node.js + Express + TypeScript
- Prisma + PostgreSQL
- React + Vite للويب
- React Native + Expo للهاتف
- OpenAPI، واختبارات وحدة وتكامل وE2E

## الحالة الحالية

تم إنشاء وثائق التأسيس فقط. لم يتم إنشاء تطبيق أو قاعدة بيانات أو واجهات API بعد، ولم تُشغّل اختبارات مشروع لأنه لا يوجد كود تطبيقي بعد.

## الخطوة التالية

إنشاء هيكل monorepo منظم، إعداد TypeScript وExpress وPrisma وPostgreSQL، ثم تنفيذ المصادقة والمتاجر والصلاحيات وعزل المستأجرين مع اختبارات مخصصة قبل بناء الميزات التجارية.
